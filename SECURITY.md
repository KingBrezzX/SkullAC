# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to the SkullAC maintainers rather than publishing an exploit before a fix is available.

Include:

- SkullAC version
- Paper version
- Java version
- Reproduction steps
- Relevant logs or stack traces
- A minimal test case when possible

## Anti-cheat bypass reports

For major detection bypasses, provide enough information for the maintainers to reproduce and verify the issue. Do not include live-player personal data or credentials.
